# Simple Gallery App

Bu proje, React Native kullanılarak geliştirilmiş basit bir resim galerisi uygulamasıdır.  
Uygulama tek ekrandan oluşur ve kullanıcı küçük resimlere dokunduğunda büyük versiyonunu görüntüleyebilir.

---

## 📌 Özellikler
- Grid şeklinde küçük resim gösterimi (FlatList + numColumns)
- Seçilen resmin büyük versiyonunun görüntülenmesi
- Açıklama metni
- Varsayılan placeholder görüntüleme
- useState ile state yönetimi
- Pressable kullanarak tıklama işlemleri
- StyleSheet ile stil yönetimi

---

## 📱 Kullanılan Teknolojiler
- React Native
- Expo
- JavaScript
